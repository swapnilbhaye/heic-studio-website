# HEIC Studio Website

A fast, responsive static marketing/download website for HEIC Studio.

## Deploy
Upload this folder to GitHub Pages, Cloudflare Pages, Netlify, or another static host.

Before deploying, replace `YOUR-DOMAIN` in `index.html` and `sitemap.xml`, and replace `YOUR_SUPPORT_LINK` with your payment/support URL.

The site links downloads to the official HEIC Studio GitHub Releases page.
